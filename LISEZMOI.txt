J.A.R.V.I.S · VEILLE  —  mode d'emploi
=======================================

LANCER SUR PC (Windows)
-----------------------
1. Double-clique sur JARVIS.bat
   -> une fenêtre noire s'ouvre (le petit serveur local) puis le site s'ouvre
      tout seul sur http://localhost:8765
   -> laisse la fenêtre noire ouverte tant que tu utilises Jarvis.
2. Utilise Chrome ou Edge (la reconnaissance vocale ne marche pas sur Firefox / Brave).
3. Clique une fois sur le cercle, autorise le micro (une seule fois), puis parle.
   Comme l'adresse est toujours http://localhost:8765, le navigateur retient
   l'autorisation : il ne la redemandera plus.
   (Astuce : la touche ESPACE fait la même chose que cliquer sur le cercle.)

Pourquoi pas juste double-cliquer sur index.html ?
   Ça marche aussi, mais en "file://" Chrome redemande le micro à chaque fois
   et les flux passent par des proxys publics, plus lents. Le .bat règle les deux.

EXEMPLES DE COMMANDES VOCALES
-----------------------------
  « Sors-moi la veille cyber »             -> tous les domaines
  « Sors-moi la veille IA »                -> IA uniquement
  « Veille OSINT de la semaine »
  « Les vulnérabilités d'aujourd'hui »
  « Veille ransomware des 3 derniers jours »
  « Veille pentest en français »           -> seulement les sources FR
  « Veille sur Microsoft »                 -> recherche libre sur un sujet
Domaines reconnus : cyber, vulnérabilités/failles/CVE, menaces/ransomware/malware,
IA, OSINT, pentest/red team/CTF, vie privée/RGPD, alertes (CERT-FR, CISA…).
Périodes : aujourd'hui, hier, X derniers jours, semaine, mois.

SUR TÉLÉPHONE
-------------
Sur téléphone, le navigateur n'autorise le micro que sur un site en HTTPS.
Le plus simple : mettre le dossier en ligne gratuitement sur GitHub Pages
(dépôt -> Settings -> Pages) ou Netlify Drop (glisser-déposer le dossier sur
app.netlify.com/drop). Le site détecte tout seul qu'il n'y a pas de serveur
local et passe par des proxys web.
- Android / Chrome : à la 1re ouverture il demande le micro ; accepte, c'est retenu.
  Menu ⋮ -> "Ajouter à l'écran d'accueil" pour l'avoir en plein écran comme une appli.
- iPhone / Safari : Réglages -> Safari -> Microphone -> "Autoriser" pour qu'il ne
  redemande plus.
- Maintiens le cercle appuyé, parle, relâche : Jarvis lance la veille.
- Le petit cercle en haut à gauche ramène à l'écran Jarvis pour une nouvelle demande.

DANS LES RÉSULTATS
------------------
- Le réacteur reste au centre, les actus tournent autour en 2 orbites :
    ▲ PRIORITAIRE (en haut) : critique (rouge), élevé (orange), « à la une » (vert)
    ▼ VEILLE (en bas)       : le reste, tendances et infos
- Pour faire tourner une orbite : glisse (souris ou doigt), molette, flèches ‹ ›
  ou touches ← → (↑ ↓ pour changer d'orbite, Entrée pour ouvrir la carte de face).
- Clique / touche une carte : elle se déplie en console horizontale (jauge de
  menace, en bref, en clair, couverture multi-sources, mots expliqués, que faire,
  CVE/éditeurs/groupes détectés, extrait de l'article, liens).
- Clique (PC) ou maintiens (tel) le réacteur du centre pour une nouvelle demande
  vocale sans quitter les résultats. Le petit réacteur en haut à gauche ramène
  à l'écran d'accueil.
- Doublons : quand plusieurs sources parlent de la même actu (même en FR et en EN),
  Jarvis les fusionne en une seule carte. « 4 SOURCES » sur la carte = 4 sources
  ont couvert l'info ; elles sont toutes listées dans le détail.
- Fiabilité des sources : ◆ vert = OFFICIEL (CERT-FR, ANSSI, CISA, NCSC, CNIL…),
  ◆ bleu = RÉFÉRENCE (médias et labos reconnus), ◇ = COMMUNAUTÉ (blogs, Reddit).
- FR / VO : traduction automatique des titres anglais.  🔊 : voix de Jarvis.
  ↻ : actualiser.  PERTINENCE / RÉCENT : ordre des cartes.

AJOUTER UNE SOURCE
------------------
Ouvre index.html, cherche "const SOURCES" et ajoute une ligne, par ex. :
  { n: 'Mon blog', u: 'https://exemple.com/feed/', c: ['cyber'], l: 'fr', t: 3 },
c = catégories : cyber, vuln, menaces, ia, osint, offensif, privacy, alertes
t = fiabilité : 1 officiel, 2 référence, 3 communauté

Note : certaines sources peuvent être injoignables un jour donné (site en panne,
flux modifié) ; survole le compteur « en ligne » en haut pour les voir. Ça n'empêche pas le reste.
